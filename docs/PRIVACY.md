# Composer Privacy Policy

_Last updated: 24 November 2026_

Composer is a Mac app for learning music theory and sketching chord progressions, rhythms and MIDI files.

## What Composer collects

Nothing. Composer does not collect, store, transmit, or share any personal data or usage data.

- **No accounts.** Composer has no sign-in and no user accounts.
- **No network access.** Composer never connects to the internet, so nothing leaves your Mac.
- **No analytics or tracking.** Composer contains no analytics, advertising, or crash-reporting frameworks.
- **No third parties.** Because no data is collected, none is shared with anyone.

## Files

Composer writes a file only when you export a MIDI file, to the place you choose in the save panel.

## Children

Composer does not knowingly collect any information from anyone, including children.

## Changes

If this policy changes, the updated version will be published at the same address with a new date.
